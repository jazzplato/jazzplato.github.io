{% comment %} Which home page a visitor sees: the classic one, or the new design at /canary/ (only the home page so far). ?ui=canary or ?ui=classic on any page picks one for good; ?ui=reset forgets the pick. Without a pick, site.canary.share (0 to 1) of visitors get the new home page. Each visitor keeps one random number, so they stay on the same side, and raising the share only moves people to the new design. {% endcomment %}
